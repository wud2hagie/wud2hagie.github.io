# Wudneh T. Mengist — Personal Website

Personal brand site for Wudneh Tilahun Mengist — Mathematician · Educator · Builder.

## Live URLs
- GitHub Pages: https://wud2hagie.github.io
- Netlify mirror: https://wudneh-wtm.netlify.app

## Tech Stack
- Next.js 16 with static export
- Tailwind CSS 4
- Framer Motion
- Deployed via GitHub Pages (free)

## Local Development
```bash
bun install
bun run dev
```

## Build
```bash
bun run build:static
```
Output goes to `out/` folder.
